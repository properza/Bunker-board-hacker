## 🛠️ ระบบถ่ายรูปและอ่านค่าจากภาพอัตโนมัติ (Visual OCR & Camera)

ไม่ต้องเสียเวลากรอกตัวเลขเองขณะที่ Beepers กำลังวิ่งมา! รองรับทั้ง:
1. **📸 ถ่ายรูปจากมือถือ (Camera)**: กดปุ่มถ่ายรูปแล้วถ่ายจอคอมได้ทันที
2. **📋 วางรูปจากคลิปบอร์ด (Ctrl+V)**: แคปหน้าจอเกมด้วย `Win + Shift + S` แล้วกด `Ctrl + V` ในเว็บได้ทันที
3. **📁 อัปโหลดรูปภาพ / ลากรูปมาวาง (Drag & Drop)**
4. **💻 เปิดกล้องเว็บแคมจากคอมพิวเตอร์**

## 🎯 ระบบกรอบอัจฉริยะ (Adjustable Guide Frames)

แอปพลิเคชันมีกรอบ 4 สีตามแผงวงจรในเกม SCUM:
* 🟡 **กรอบสีเหลือง (SWITCHES SW8 - SW1):** ครอบคลุมแถวสวิตช์ทั้ง 8 แถว x 2 ฝั่ง (A แดง / B ฟ้า)
* 🔴 **กรอบสีแดง (GOAL A):** ตัวเลข Output A (สายแดง)
* 🔵 **กรอบสีฟ้า (GOAL B):** ตัวเลข Output B (สายฟ้า)
* 🟢 **กรอบสีเขียว (INPUT):** ตัวเลขเริ่มต้น Input ที่หน้าจอด้านล่าง

> สามารถใช้เมาส์หรือนิ้วลากย้ายตำแหน่งและย่อขยายกรอบให้ตรงกับรูปถ่ายของคุณได้อย่างอิสระ!

## 🚀 ระบบประมวลผล OCR 2 รูปแบบ

* **Tesseract OCR (ออฟไลน์ 100%):** ทำงานในบราวเซอร์ทันที ไม่ต้องต่อเซิร์ฟเวอร์ ไม่ต้องใช้ API Key มีระบบกรองสีและแปลงภาพขาวดำเพื่อความแม่นยำสูงสุด
* **Gemini AI Vision (แม่นยำ 100%):** สำหรับผู้ที่ใส่ Gemini API Key ฟรี วิเคราะห์ภาพได้แบบคมกริบ แม้ภาพจะเอียงหรือเบลอ

## 🕹️ วิธีใช้งาน

1. เปิดไฟล์ `index.html` หรือเข้าผ่านเว็บ
2. กดถ่ายรูป หรือกด `Ctrl + V` เพื่อวางรูปภาพแผงสวิตช์
3. ขยับกรอบสีให้ตรงกับตำแหน่งในรูป
4. กด **"สแกนอ่านค่าตามกรอบ (SCAN & SOLVE)"**
5. ระบบจะอ่านค่า กรอกตัวเลขลงช่อง และสับสวิตช์ไฟเขียว (LED ON) ให้ทันที!
